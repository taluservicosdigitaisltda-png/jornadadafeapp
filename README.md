# Jornada Fé App

Crie uma página de obrigado com oferta de upsell para o produto digital “Jornada da Fé”.

OBJETIVO DA PÁGINA

Esta página será exibida imediatamente após a compra do curso Jornada da Fé. Ela deve:

1. Confirmar que a compra principal foi aprovada.

2. Informar que o acesso ao curso será enviado por e-mail.

3. Apresentar como oferta complementar o “Aplicativo Jornada da Fé”.

4. Direcionar o cliente ao checkout do aplicativo.

A oferta do aplicativo é opcional e deve ser apresentada de forma clara, elegante e persuasiva, sem falsas promessas ou escassez artificial.

CONFIGURAÇÃO DO PROJETO

* Criar uma landing page de uma única rota.

* Idioma: português brasileiro.

* Usar React e Tailwind CSS.

* Página totalmente responsiva.

* Priorizar carregamento rápido.

* Não utilizar banco de dados.

* Não exigir login.

* Não criar formulários.

* Usar HTML semântico e boas práticas de acessibilidade.

* Os componentes podem ser organizados em arquivos separados.

* O resultado deve estar pronto para publicação.

* Todos os botões de compra devem direcionar para:

https://go.perfectpay.com.br/PPU38CQFKP5

Estilo:

* Gradientes discretos.

* Bordas douradas finas.

IMAGENS

Utilizar os seguintes arquivos enviados:

Não substituir a logo por texto comum e não recriar a logo. Preservar sua proporção e qualidade.

RESPONSIVIDADE

Desktop:

* Seções principais em duas colunas.

* Largura máxima do conteúdo: aproximadamente 1140px.

* Espaçamentos amplos.

* Imagem do aplicativo ao lado da oferta.

Tablet:

* Reduzir tamanhos e espaçamentos.

* Benefícios em duas colunas.

* Demais seções podem passar para uma coluna.

Celular:

* Todas as seções em uma coluna.

* Conteúdo centralizado quando apropriado.

* Botões ocupando 100% da largura disponível.

* Preço e textos perfeitamente legíveis.

* Benefícios em uma coluna.

* Não permitir rolagem horizontal.

* Manter áreas de toque confortáveis.

* Preservar a proporção das imagens.

* Garantir que o cartão flutuante não ultrapasse a tela.

CONVERSÃO E USABILIDADE

* Todos os botões devem utilizar exatamente o mesmo checkout.

* Não criar botão sem funcionamento.

* Não adicionar contador regressivo.

* Não adicionar pop-ups.

* Pode criar depoimentos.

* Pode colocar mais de 30.000 alunos.

* Utilizar mensagens de urgência.

* Não alterar o preço.

* Não apresentar assinatura ou mensalidade.

* Informar claramente que a compra principal já foi aprovada.

* Informar claramente que o aplicativo é uma oferta opcional.

* Abrir o checkout ao clicar no botão.

* Adicionar estados de hover e foco nos botões.

* Garantir contraste adequado.

* Manter o conteúdo rápido, elegante e fácil de navegar.

Antes de finalizar, revise a página completa no desktop e no celular. Confirme que todos os botões direcionam para o checkout correto e que nenhuma imagem está quebrada.
